# 广告报表部署实施计划

目标：将现有HTML封装为远程可访问的项目，发布到 fidigit/adver_data，交付服务器部署命令。

设计：保留原报表及汇总数据，复制到 public/index.html。使用 Node.js 内置 HTTP 服务，提供首页和 /api/health；无需数据库、构建工具或第三方运行依赖。沿用商务人效项目 main 分支加 v0.0.1 标签的发布流程。Windows 直接启动，Linux 可使用 Docker Compose 常驻运行。

1. 阅读原HTML和商务人效项目部署文档，确认资源及数据依赖。
2. 新建服务入口、配置样例、Docker配置和Windows启动脚本。
3. 验证HTTP响应、健康接口、禁止访问源码和配置文件，并检查原脚本语法。
4. 在浏览器检查报表加载、筛选和图表交互；确认部署副本与原HTML一致。
5. 编写Windows与Docker部署、升级和回滚命令；记录实际验证范围。
6. 提交main和v0.0.1，推送到用户指定仓库，核对远端提交。
